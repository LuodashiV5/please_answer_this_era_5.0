# 一、时域和频域

任何实际工程中的信号波形，都可以看作是由一系列不同频率、不同幅值的正弦波叠加合成的结果。每一个正弦分量都具有其独立的频率和幅值，共同构成了复杂的时域波形。

相比于仅在时域观察信号随时间的变化过程，在频域中对信号进行分析往往更具实用价值。因为频域分析能够将混杂在一起的信号分解为各个频率成分，清晰地展示出信号内部的结构特征，从而更深刻、更全面地揭示信号的本质。

# 二、傅里叶变换

信号从时域到频域的变换（以及逆变换），通过傅里叶变换来实现。

- 时域 → FFT → 频域
    
- 频域 → IFFT → 时域
